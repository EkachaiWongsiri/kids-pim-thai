# Kids Pim Thai (เกมฝึกพิมพ์ดีดภาษาไทยและอังกฤษสำหรับเด็ก) 🚀

เกมฝึกพิมพ์ดีดสำหรับเด็ก ออกแบบให้เล่นง่าย สนุกสนาน กราฟิกสีสันสดใส มีระบบป้อมปืนเลเซอร์ยิงทำลายคำที่ตกลงมาจากฟ้า พร้อมเสียงอ่านออกเสียงพยัญชนะ/สระ และเอฟเฟกต์ SFX สมจริง

---

## 🌟 ฟีเจอร์เด่น

1. **โหมดเกมเพลย์ Laser Cannon Blast**:
   - คำศัพท์และตัวอักษรลอยอยู่ในบอลลูน/ฟองสบู่หลากสี ลอยลงมาจากฟ้า
   - ป้อมปืนเลเซอร์ด้านล่างจะเล็งและยิงลำแสงเลเซอร์ทำลายคำทันทีเมื่อพิมพ์ถูกต้อง
   - เอฟเฟกต์พลุระเบิด (Confetti Sparks) และระบบ Combo Streak

2. **ระบบเสียงสมจริง & การสอนภาษา (Zero-External Dependency)**:
   - **Web Speech API**: ออกเสียงตัวอักษร/สระทันทีเมื่อกดถูก เช่น "ก ไก่", "ข ไข่", "สระ อา", "ไม้เอก" และอ่านออกเสียงคำศัพท์เต็มเมื่อทำลายคำสำเร็จ
   - **Web Audio API**: สังเคราะห์เสียง SFX เลเซอร์, ระเบิด, เสียงคอมโบ, เสียงหัวใจลด และเพลงเฉลิมฉลอง

3. **แป้นพิมพ์จำลอง Interactive Virtual Keyboard**:
   - รองรับทั้งภาษาไทย (เกษมณี) และอังกฤษ (QWERTY)
   - ไฮไลท์ปุ่มเป้าหมายที่ต้องกดถัดไป (Pulsing Glow)
   - ไฮไลท์ปุ่ม Shift อัตโนมัติเมื่อต้องกดตัวอักษร Shift (เช่น ษ ศ ฤ ฆ ฯลฯ)
   - แถบสีระบุตำแหน่งนิ้วมือทั้ง 8 นิ้ว ช่วยสอนการวางนิ้วที่ถูกต้อง
   - รองรับการกดสัมผัสบนหน้าจอแท็บเล็ต/มือถือ หรือพิมพ์ผ่านคีย์บอร์ดจริง

4. **ระบบด่าน & การเลือกด่านอย่างอิสระ**:
   - สามารถเลือกเล่นด่านใดก็ได้ทันที ไม่ต้องรอปลดล็อค
   - **ด่านภาษาไทย 10 ด่าน**: เริ่มจากแป้นเหย้า (Home row: ฟ ห ก ด ่ า ส ว) -> แถวบน -> แถวล่าง -> สระ/วรรณยุกต์ -> คำศัพท์สัตว์ -> ผลไม้ -> ครอบครัว -> ปุ่ม Shift -> ประโยค
   - **ด่านภาษาอังกฤษ 7 ด่าน**: Home row -> Top row -> Bottom row -> Animals -> Treats -> Colors -> Sentences

5. **ปรับความเร็วได้ละเอียด (Speed Multiplier)**:
   - ปรับความเร็วได้ตั้งแต่ `x0.1`, `x0.2`, `x0.5`, `x0.8`, `x1.0`, `x1.2`, `x1.5`, `x2.0` (เหมาะกับเด็กเล็กที่เพิ่งหัดพิมพ์)

6. **คลังคำศัพท์ที่กำหนดเอง (Custom Word Bank)**:
   - ผู้ปกครองหรือคุณครูสามารถป้อนคำศัพท์ที่ต้องการให้เด็กฝึกพิมพ์ได้เอง หรือเลือกจากหมวดแนะนำ

7. **ระบบจัดเก็บข้อมูล Offline-First**:
   - บันทึกคะแนนสูงสุด (High Score), สถิติความเร็ว (WPM), ความแม่นยำ (Accuracy) และการตั้งค่าลงใน `LocalStorage` 100% เล่นได้โดยไม่ต้อง Login

## 🛠️ วิธีการรันโปรเจ็คในเครื่องเพื่อทดสอบ (Development)

```bash
# ติดตั้ง dependencies (หากยังไม่ได้ติดตั้ง)
npm install

# รันโหมด Development server
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:3000`

---

## 🚀 วิธีการ Build และนำไป Deploy บน https://www.mxiaapp.com/th/app/kids-pim-thai

```bash
# สั่ง Build เป็น Static HTML/CSS/JS Bundle
npm run build
```

หลังจากคำสั่งทำงานเสร็จ จะได้โฟลเดอร์ `dist/` ซึ่งประกอบด้วย:
- `dist/index.html`
- `dist/assets/index-*.js`
- `dist/assets/index-*.css`

นำไฟล์ทั้งหมดภายในโฟลเดอร์ `dist/` ไปวางที่ Directory หรือ Routing ของ Subpath:
`/th/app/kids-pim-thai` หรือโฮสต์ผ่าน Firebase Hosting / Static Web Server ได้ทันที
(ตั้งค่า `base: './'` ไว้ใน `vite.config.ts` เรียบร้อยแล้ว ทำให้รองรับ Relative Path ได้ทุกสภาพแวดล้อม)
